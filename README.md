# customer_points_app
# 🎁 Customer Points System (نظام نقاط العملاء)

تطبيق بسيط تم بناؤه باستخدام **Python + Streamlit** لإدارة نقاط العملاء بشكل تفاعلي.

## 🧩 فكرة المشروع:
يسمح التطبيق للمستخدمين بإدخال:
- اسم العميل
- عدد النقاط المكتسبة

ثم يتم حساب **إجمالي النقاط** وتحديثها مباشرة في واجهة سهلة الاستخدام.

## 🚀 التقنيات المستخدمة:
- Python
- Streamlit

## 💻 التشغيل المحلي:
```bash
pip install streamlit
streamlit run customer_points_app.py
